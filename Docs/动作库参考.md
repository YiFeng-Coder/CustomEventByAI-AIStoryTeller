# 动作库参考（42 个）

版本 0.6.0。这是 Lua 脚本能调用的全部动作；表里的上限就是校验器里的上限，
越界会导致**整段脚本**被拒（不是只跳过那一条）。

权限列：`叙事` 无副作用或仅 UI；`生成` 有界生成；`重大` 会伤人或改变世界，受危险/编辑预算约束。

---

## 0. 两个新写法（0.6.0）

### 位置：用 spot，不要猜坐标

以前所有位置都是绝对坐标 `{x,y,z}`，模型不知道地图多大，猜错就整段作废。
现在写语义锚点，由 C# 翻译成真实格（老写法 `cell={x,y,z}` 仍然可用）：

| 锚点 | 含义 |
|---|---|
| `center` / `colony_center` / `base` | 基地中心 |
| `storage` | 仓储区里随机一格（没有仓储区会报错） |
| `water` | 中心 40 格内最近的水面 |
| `ore` | 地图上随机一处可开采的矿 |
| `edge_north` / `edge_south` / `edge_east` / `edge_west` | 某一侧地图边缘 |
| `random` | 基地附近随机一格 |
| `handle:名字` | 某个句柄当前所在的位置 |

可加 `offset={x=0,y=0}` 做相对偏移，或 `jitter=0..12` 随机散开（用于"一片"而不是"一点"）。
锚点解析失败**会报错**，不会静默落到别的格子。

### 目标：用 who

角色类动作不再只能指向"本事件生成的角色"：

| 写法 | 含义 |
|---|---|
| `handle:p1` | 本事件自己生成的角色（老写法，兼容） |
| `colonist:米娅` | 你的殖民者（按名字） |
| `best:Shooting` | 某技能最高的殖民者 |
| `worst:Mood` | 心情最差的殖民者 |

**能不能落到你的殖民者身上，由动作的"目标策略"决定**（写在校验器里，不是提示词里）：

- 危险动作（`pawn.hurt` / `pawn.kill` / `pawn.mental`）只能用 `handle:`，永远不能指向你的殖民者；
- 身份类动作（`pawn.trait` / `pawn.relation` / `pawn.set_skill` / `pawn.join`）只对 AI 生成的角色生效；
- 心理层（想法 / 心情）默认也只对 AI 生成的角色生效，玩家可以在设置里打开
  「允许心理层影响你的殖民者」；
- 正向动作（`pawn.heal` / `pawn.inspiration`）对你的殖民者一律可用。

## 句柄（handle）怎么用

Lua 里没有对象引用，所以"之后还要操作某个东西"必须先给它起名：

`~lua
if ctx.trigger == "start" then
  -- 生成一个角色，并登记成 p1
  actions[#actions+1] = { opId = "a1", type = "pawn.spawn",
    args = { pawnKind = "Villager", count = 1, handle = "p1" } }

  -- 同一阶段里紧接着用 p1（0.6.0 起可用：校验阶段把它当作"待生成"放行）
  actions[#actions+1] = { opId = "a2", type = "pawn.hurt",
    args = { who = "handle:p1", hediffDef = "Cut", severity = 0.4 } }
end
`~

- 句柄随事件实例存档，**读档后依然能解析**；
- 解析失败（对象被摧毁 / 确实没生成）→ 该动作校验失败 → 整阶段作废；
- 每个实例最多记 32 个句柄。

## 提示词里只显示"这次用得上"的动作组

动作库有 42 个，但一次编剧请求不会把 42 行手册全塞进去（会顶到 10k 字）：

- 常驻：叙事 + 生成 + 地图 + 角色（23 个）；
- 按剧情关键词出现：心理 / 场景 / 交互 / 世界，最多再加两组；
- 玩家在设置里关掉的组一律不出现。

**裁剪只影响"提示词里看不看得到"，不影响能不能执行**——运行时白名单始终是全部 42 个，
所以模型写出没展示的动作照样能跑。调试窗顶部的"本次可见"会显示这次给了几组。
