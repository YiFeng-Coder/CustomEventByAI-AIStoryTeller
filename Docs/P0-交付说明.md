## 2. 怎么构建

```powershell
cd D:\SteamA\steamapps\common\RimWorld\Mods\AIIncidents
powershell -ExecutionPolicy Bypass -File .\tools\build.ps1
```

产出：`1.7\Assemblies\AINarrator.dll`。

脚本自动挑工具链，规则如下：

1. **宿主**优先用系统 `C:\Program Files\dotnet\dotnet.exe`，`csc.dll` 用同一套 SDK 里的 Roslyn；
2. 找不到系统 SDK 才退回便携版 `Mods\PioneerFrameworkLite\.zcode\dotnet10`；
3. **net10.0 引用程序集**从 `packs\Microsoft.NETCore.App.Ref\10.*` 里找（系统 packs 优先，其次便携 SDK）。

> 为什么这样排：本机那份便携 SDK 的宿主在初始化首次运行状态时写不了自己的哨兵文件，之后凡是它要写的路径都被拒（`CS2012`、`MSBuild` 建临时目录失败）。换成系统宿主 + 系统 csc、只借它的 net10 引用包，就能正常产出 DLL。这是环境问题，不是代码问题。

显式指定路径：

```powershell
powershell -File .\tools\build.ps1 -GameDir "D:\SteamA\steamapps\common\RimWorld" -RefPackRoot "D:\...\Microsoft.NETCore.App.Ref"
```

只做编译检查、不写产物：

```powershell
powershell -File .\tools\build.ps1 -CheckOnly   # 期望 COMPILE-CHECK PASSED
```

> 注意：`build.ps1` 必须是纯 ASCII 注释。Windows PowerShell 5.1 读 UTF-8 无 BOM 的中文会解析失败——我踩过这个坑，别在脚本里写中文。

## 3. 游戏内验证清单（P0 验收）

1. 启动游戏，模组列表启用 **AI Narrator**（应自动勾上 Harmony 与 RimLua）。
2. 开新档或读档，叙述者选择界面应能看到 **「AI 叙述者」**（`listOrder=25`，肖像暂时复用原版 Randy 的贴图）。
3. 选中它、开始游戏，`Player.log` 里应出现：
   - `[AI Narrator] loaded. provider=..., model=..., configured=False, autoTrigger=True`
   - `[AI Narrator] candidate incidents=N (scanned M IncidentDefs) categories: ThreatBig=.. ThreatSmall=.. Misc=..`
   - `[AI Narrator] world state component created.`
4. 选项 → 模组设置 → **AI 叙述者**：能看到设置页、拖动滑块不报错、填入接口地址/模型/Key 后状态变成「已完整」。

**P0 故意不做的事**：不产生任何事件（`MakeIntervalIncidents` 直接 `yield break`）。所以进游戏后除了上述日志，行为与原版叙述者不同——威胁事件不会自己来。这是预期，P1 接上导演后才有事件。
